# Security Policy

## Supported Versions

| Version | Supported          |
|:-------:|:------------------:|
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

---

## Non-Clinical & Synthetic Data Mandate

- **Synthetic Data**: Public demonstrations, seeded cohorts, and automated tests use **synthetic, randomly generated data**. Do not upload or commit real Protected Health Information (PHI) or Personally Identifiable Information (PII) to public repositories.
- **Operational Prototype**: PFIS models non-clinical operational logistics (transportation, daily wage loss, digital literacy, documentation hurdles). It is not a clinical medical diagnostic system.

---

## Reporting a Security Vulnerability

If you discover a vulnerability or potential security flaw:

1. **Do not create a public GitHub issue.**
2. Send an email with vulnerability details, reproduction steps, and potential impact to: `security@satyamhq.org`
3. We will acknowledge receipt within 48 hours and coordinate a coordinated fix and release timeline.
